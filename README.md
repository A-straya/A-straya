### `> trust nothing`

The internet is a hostile network that happens to carry cat videos. Everything I build assumes someone is watching, scanning or logging.

-  **scan yourself first**: if I can find it, so can they
-  **least privilege** by default
-  **logs or it didn't happen**
-  **encrypt** what you'd hate to see in a pcap
